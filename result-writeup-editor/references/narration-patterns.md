# Narration patterns

Process narration is a sentence whose subject is the author and whose job is to report the work. Convert it to a statement of the finding, keeping the number and the cause.

## Chinese patterns
| Pattern | Typical form | Convert to |
|---|---|---|
| Work report | 我做了…… / 我查了…… / 我跑了…… / 我写了一份…… | the result, with the cause: 排查：…… |
| Stage-setting | 我先……然后……最后…… | the sequence only if the order matters; otherwise the end state |
| Self-correction story | 我第一反应写的是……后来审查指出…… | 原先的结论“……”说过头了：理由。准确说法是…… |
| Worry | 我怀疑…… / 我担心…… | 候选解释：……（已排查/未排查） |
| Decision log | 我把……改成了…… | 改为……（原因） |
| Self-assessment frame | 我写过一份很苛刻的自评，大意是…… | the assessment itself |
| Mood | 我当时的想法是…… | keep only if it is the author's stance and the author confirms it |

## English patterns
| Pattern | Convert to |
|---|---|
| I ran / checked / tested X and found Y | X shows Y. |
| I then changed A to B | A was changed to B because C. |
| I first thought X, but the review showed Y | The earlier claim X was too strong: Y. |
| I was worried that | One possible artifact is ...; checked: ... |

## Keep (do not convert)
- A stance or decision the author can defend: "I would not call this equivalence without the interval."
- An experience only this author had, when it carries the lesson.
- One or two failure stories per document.

## Conversion test
After converting, ask: does the reader still learn (1) what was found, (2) why, (3) what changed? If any of the three is missing, the conversion removed content, not narration.
