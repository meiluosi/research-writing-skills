# Conflict rules

| Conflict | Rule |
|---|---|
| Add the author's experience vs cut process narration | Stance, trade-off, and unique experience are kept or added; task logistics ("I ran, I wrote, I changed") are cut. |
| Concision vs hedge | The hedge stays if it carries uncertainty. |
| Concision vs number | Numbers, intervals, and sample sizes stay. |
| Pattern rule vs author voice sample | The sample wins. |
| Pattern list vs domain term | The domain term wins when used literally. |
| Plain-language analogy vs exact mechanism | Both: analogy first, exact mechanism with parameters second; the analogy must not imply a mechanism the system lacks. |
| Subtraction vs a failure story | Keep one or two failure stories if they carry the lesson; state the rest as facts. |
| Heading spine vs the author's own titles | Propose the spine; keep a title the author insists on and note the exception. |
| Edit vs a claim that looks wrong | Do not silently fix. Flag to the author; escalate to `independent-review`. |
