# 中文机器腔模式

每条给出：表现、为什么算问题、怎么改。标 ⚠ 的词在专业语境里可能是正当术语，先看上下文再动。

## 一、铺垫与收尾
| 表现 | 改法 |
|---|---|
| 在当今……时代 / 随着……的快速发展 / 众所周知 / 不可否认 | 删，直接说事实 |
| 值得注意的是 / 需要强调的是 / 不得不说 | 删，若真重要就用数字或位置表达 |
| 总而言之 / 综上所述 / 总的来说 / 希望对你有所帮助 | 删；结尾用最后一个事实收 |
| 让我们一起…… / 接下来我们来看看 | 删，直接进入内容 |

## 二、对比与金句
| 表现 | 改法 |
|---|---|
| 这不是X，而是Y / 不仅X，更Y | 直接写Y |
| 真正的……从来不是……而是…… | 直接写结论和依据 |
| 一句话收尾重复前文（“这，就是……”） | 删 |
| 听起来像标语的句子 | 改成具体的事或数字 |

## 三、节奏
| 表现 | 改法 |
|---|---|
| 三联排比（A、B、C 同构） | 保留真有三项的，其余合并或删到两项 |
| 连续几句同一开头（“它……它……它……”） | 换主语或合句 |
| 首先/其次/再次/最后 套所有列表 | 无顺序依赖的用无序列表；有顺序的才保留序号 |
| 连续多个“的”字短语、“进行……”“加以……”“予以……” | 还原为动词（“进行检查”→“检查”） |

## 四、空洞拔高
| 表现 | 改法 |
|---|---|
| 至关重要 / 极其 / 毫无疑问 / 全方位 / 多维度 | 给出可检验的量或删 |
| 赋能 ⚠ / 抓手 ⚠ / 闭环 ⚠ / 底层逻辑 ⚠ / 颗粒度 ⚠ / 沉淀 ⚠ / 打通 ⚠ | 换成具体动作；工程语境里“闭环”“链路”若指实际流程则保留 |
| 深入探讨 / 全面剖析 | 说明探讨了什么 |
| 有研究表明 / 专家认为（无出处） | 给出处或删 |

## 五、版式
| 表现 | 改法 |
|---|---|
| 每项加粗、emoji 当标题装饰 | 只加粗读者不能错过的 |
| 标题像口号（“让增长飞起来”） | 标题写功能和要点（见 result-writeup-editor 的标题脊柱） |
| 每节之间都有分割线 | 只在真正换话题处用 |

## 六、聊天残留与写文档的文档
| 表现 | 改法 |
|---|---|
| “好的，以下是……” / “当然可以” | 删 |
| “本文将从三个方面……” / “下表对比了……” / “根据以上分析” | 直接给内容 |
| “作为一个 AI……” “截至我的知识截止日期” | 删或改成来源说明 |

## 保留清单（不要误伤）
引文、标题、专有名词、讨论该词本身的段落、专业术语的字面用法、作者本人的口头禅（作者确认后）。
