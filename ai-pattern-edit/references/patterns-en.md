# English pattern notes and sources

The English pattern lists are well covered by existing open skills. Use them for the long tail and use this skill for the workflow, the Chinese list, the domain-term guard, and the preservation check.

- `blader/humanizer` (MIT): 26 numbered patterns grouped as staging, rhythm, inflation, formatting, leftovers, wrong reader; strong on "writing about the document" and "re-explaining what the reader knows".
- `hardikpandya/stop-slop` (MIT): short phrase and structure lists plus a five-dimension self-score.
- `conorbronsdon/avoid-ai-writing` (MIT): severity tiers (credibility killers, obvious smell, polish), detect / rewrite / edit modes, and a router with a preservation verifier.

Group summary used here: staging (not-X-but-Y, closers, run-ups), rhythm by rule (triads, repeated openings, dash overuse, stacked hedges), inflation (significance words, vague association, -ing riders, sales language), borrowed authority, formatting by rule, leftovers, writing about the document, wrong reader.

When these skills are installed, prefer their English lists; keep this skill's guard and preservation steps.
